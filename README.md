# elegant-mermaid

elegant-mermaid is a Mermaid renderer, an ASCII and terminal renderer, a checker, and a linter. It is implemented in idiomatic Go and in idiomatic Rust, with a Lean 4 reference implementation. Each implementation is usable as the `emd` command-line tool and as an embedded library.
