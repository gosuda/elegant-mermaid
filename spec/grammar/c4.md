# C4 grammar

This file fixes the lexical rules, the grammar, the abstract syntax tree, the semantic resolution, and the diagnostics of the `c4` kind.

## Scope

- c4-01: The grammar authority MUST be `.references/mermaid/packages/mermaid/src/diagrams/c4/parser/c4Diagram.jison`, with `c4Db.ts` for resolution. [just oracle]
- c4-02: The parser MUST accept the statement forms below for all five C4 headers without a diagram-level restriction on macro families. [just oracle]
- c4-03: Shared preprocessing, source positions, nesting limits, and configuration diagnostics MUST follow their kind-independent specifications. [just parity]

## Header forms

- c4-04: The header MUST be `C4Context`, `C4Container`, `C4Component`, `C4Dynamic`, or `C4Deployment`, case-sensitive, with the shared keyword boundary. [just oracle]
- c4-05: A header MUST end with a line separator before its statements; the resolved kind MUST be `c4` and MUST retain the selected header as its C4 type. [just parity]

- c4-08: Literal macro rules MUST match a complete macro name followed by optional whitespace and `(`; this token boundary MUST prevent an earlier short name from hiding its longer variants. [just oracle]

- c4-11: An unquoted STR MUST retain the authority's non-comma scan, including parentheses inside that token; a closing parenthesis MUST close a call only when rule 164 sees it at a token boundary. [just oracle]

## Grammar

- c4-12: The parser MUST use this EBNF without backtracking; parentheses in a call are consumed by the macro and attribute modes rather than emitted as grammar terminals. [just parity]

```ebnf
start = mermaidDoc | direction ;
direction = direction_tb | direction_bt | direction_rl | direction_lr ;
mermaidDoc = graphConfig ;
graphConfig = header, NEWLINE, statements, EOF ;
header = C4_CONTEXT | C4_CONTAINER | C4_COMPONENT | C4_DYNAMIC | C4_DEPLOYMENT ;
statements = otherStatements | diagramStatements | otherStatements, diagramStatements ;
otherStatements = otherStatement, [ NEWLINE, [ otherStatements ] ] ;
otherStatement = title | accDescription | acc_title, acc_title_value
               | acc_descr, acc_descr_value | acc_descr_multiline_value ;
boundaryStatement = boundaryStartStatement, diagramStatements, boundaryStopStatement ;
boundaryStartStatement = boundaryStart, (LBRACE, NEWLINE | NEWLINE, LBRACE, [ NEWLINE ]) ;
boundaryStart = (ENTERPRISE_BOUNDARY | SYSTEM_BOUNDARY | BOUNDARY | CONTAINER_BOUNDARY
              | NODE | NODE_L | NODE_R), attributes ;
boundaryStopStatement = RBRACE ;
diagramStatements = diagramStatement, [ NEWLINE, [ statements ] ] ;
diagramStatement = elementMacro, attributes | boundaryStatement | relationMacro, attributes
                 | UPDATE_EL_STYLE, attributes | UPDATE_REL_STYLE, attributes
                 | UPDATE_LAYOUT_CONFIG, attributes ;
elementMacro = PERSON | PERSON_EXT | SYSTEM | SYSTEM_DB | SYSTEM_QUEUE
             | SYSTEM_EXT | SYSTEM_EXT_DB | SYSTEM_EXT_QUEUE
             | CONTAINER | CONTAINER_DB | CONTAINER_QUEUE | CONTAINER_EXT
             | CONTAINER_EXT_DB | CONTAINER_EXT_QUEUE
             | COMPONENT | COMPONENT_DB | COMPONENT_QUEUE | COMPONENT_EXT
             | COMPONENT_EXT_DB | COMPONENT_EXT_QUEUE ;
relationMacro = REL | BIREL | REL_U | REL_D | REL_L | REL_R | REL_B | REL_INDEX ;
attributes = attribute, { attribute } ;
attribute = STR | STR_KEY, STR_VALUE | ATTRIBUTE | ATTRIBUTE_EMPTY ;
```

- c4-13: An empty call or empty diagram body MUST be rejected because attributes and statements are non-empty; an empty quoted argument MUST count as one empty attribute. [just oracle]
- c4-14: ATTRIBUTE MUST remain unreachable because no lexer rule emits it; SPACE, EOL, and EOF_IN_STRUCT MUST NOT add accepted productions. [just oracle]
- c4-15: A boundary MUST contain diagramStatements and MUST use one of the three brace/newline arrangements above; semicolon MUST NOT be a statement separator. [just oracle]

## Statement boundary

- c4-16: Recovery MUST stop at the next physical line ending outside a quoted argument or accessibility block, or before the current boundary's closing brace. [just go-check]
- c4-17: Recovery MUST preserve an enclosing closing brace and MUST consume an unmatched top-level closing brace after reporting it. [just go-check]
- c4-18: An unknown statement MUST NOT create an element, boundary, or relation; a recognized malformed call MUST use unexpected-token unless its delimiter remains open at end of input. [just parity]

## Abstract syntax tree

- c4-19: AST nodes MUST use these upstream production names in PascalCase and MUST span the first source token through the last source token, without a trailing separator. [just parity]

| Node | Fields | Span rule |
|---|---|---|
| Start | MermaidDoc or Direction | selected child |
| Direction | direction | direction token |
| MermaidDoc | GraphConfig | selected child |
| GraphConfig | header, Statements | header through final statement |
| Statements | ordered OtherStatements and DiagramStatements | first through last child |
| OtherStatements | ordered OtherStatement values | first through last child |
| OtherStatement | title or description form, value | keyword through value; block form includes braces |
| BoundaryStatement | BoundaryStartStatement, DiagramStatements, BoundaryStopStatement | macro through closing brace |
| BoundaryStartStatement | BoundaryStart, brace | macro through opening brace |
| BoundaryStart | macro, Attributes | macro through closing parenthesis |
| BoundaryStopStatement | close | closing brace |
| DiagramStatements | ordered DiagramStatement values | first through last child |
| DiagramStatement | macro and Attributes, or BoundaryStatement | complete call or boundary |
| Attributes | ordered Attribute values | opening through closing parenthesis |
| Attribute | positional text, named key/value, or empty | full argument; empty slot uses its comma or empty quotes |

- c4-20: Tokens MUST borrow source text; the model MUST retain macro, alias, endpoint, attribute, boundary, and accessibility spans. For title and accDescription, the AST value and its byte span MUST start after the ASCII keyword and exactly one complete separator character accepted by the lexer. U+00A0 (NBSP) and U+2003 (EM SPACE) MUST each be consumed as one complete separator character, not one UTF-8 byte. AST raw text and value spans MUST retain all further leading and trailing value whitespace. [just parity]

## Semantic resolution

- c4-21: Resolution MUST process declarations in source order and MUST preserve the first insertion position of each element alias, boundary alias, and ordered relation endpoint pair. [just parity]
- c4-22: Person and System macros MUST use positional slots `alias, label, descr, sprite, tags, link`; Container and Component macros MUST use `alias, label, techn, descr, sprite, tags, link`. [just oracle]
- c4-23: Person_Ext MUST resolve to external_person; System, Container, and Component MUST retain their base family, optional `_db` or `_queue` shape, and external flag from the exact macro spelling. [just parity]
- c4-24: A repeated element alias MUST update that element, its macro type, label, current parent boundary, and wrap state without moving its insertion position; a missing label MUST become empty text and omitted optional text MUST preserve an earlier value or default to empty text. [just oracle]
- c4-25: Boundary MUST use `alias, label, type, tags, link`; Enterprise_Boundary and System_Boundary MUST insert ENTERPRISE and SYSTEM at slot 2; Container_Boundary MUST insert CONTAINER at slot 2. [just oracle]
- c4-26: Deployment_Node and Node MUST resolve to node; Node_L and Node_R MUST resolve to nodeL and nodeR; each MUST use `alias, label, type, descr, sprite, tags, link` and MUST open a boundary body. [just oracle]
- c4-27: Boundary resolution MUST start in an implicit global scope, assign the current scope as parent, push that scope on entry, and restore it on close; the implicit scope MUST NOT emit a visible cluster. [just parity]
- c4-28: A repeated boundary alias MUST update the existing boundary in place; omitted type MUST reset to system for Boundary, container for the container helper, or node for deployment nodes. [just oracle]
- c4-29: Relations MUST use `from, to, label, techn, descr, sprite, tags, link`; RelIndex MUST discard its first argument before applying those slots and MUST resolve as Rel. [just oracle]
- c4-30: A relation missing from, to, or label MUST contribute no relation; a repeated ordered endpoint pair MUST update its relation in place, not create a parallel relation. [just oracle]
- c4-31: BiRel MUST retain two-ended marker intent and Rel_Back MUST retain reverse-marker intent; neither MUST reverse the stored endpoint pair. Rel_Back MUST put its only point marker at the stored from endpoint. [just parity]
- c4-32: Optional arguments of the form `$key="value"` MUST assign that named field regardless of the optional slot occupied; label, descr, techn, and type MUST hold text values while other fields MUST hold scalar strings. [just oracle]
- c4-33: Required alias, label, from, and to slots MUST remain positional; extra arguments beyond a helper's signature MUST have no model effect. [just oracle]
- c4-34: UpdateElementStyle MUST locate an existing element before a boundary by alias and MUST accept `elementName, bgColor, fontColor, borderColor, shadowing, shape, sprite, techn, legendText, legendSprite`; an unknown target MUST have no effect. [just oracle]
- c4-35: UpdateRelStyle MUST locate an existing ordered endpoint pair and MUST accept `from, to, textColor, lineColor, offsetX, offsetY`; an unknown pair MUST have no effect. [just oracle]
- c4-36: Update calls MUST accept named overrides in optional slots; offset values MUST use their leading signed decimal integer when present and MUST remain non-geometric metadata when no integer is present. [just parity]
- c4-37: UpdateLayoutConfig MUST accept two positional or named values and MUST retain only leading decimal integers at least 1 as c4ShapeInRow and c4BoundaryInRow; the layered engine MUST ignore these row-count hints. [just parity]
- c4-38: Style, sprite, tags, link, and layout-hint attributes MUST remain model metadata where the shared scene, theme, and interaction rules do not read them; they MUST NOT introduce shadows, host fonts, or another layout engine. [just parity]
- c4-39: title and accTitle MUST update the same title in declaration order; accDescription and both accDescr forms MUST update the accessibility description. Semantic resolution MUST trim outer whitespace from all these metadata values without changing AST raw text or spans. [just oracle]
- c4-40: Boundaries and deployment nodes MUST become layered clusters; element boxes MUST size from their text under the layered text rule without C4-specific size constants. [just parity]
- c4-41: Directional relations MUST set only the port sides below; ranking and ordering MUST remain unchanged. [just parity]

| Macro | Source side | Target side |
|---|---|---|
| Rel_Up, Rel_U | T | B |
| Rel_Down, Rel_D | B | T |
| Rel_Left, Rel_L | L | R |
| Rel_Right, Rel_R | R | L |

- c4-42: Rel, BiRel, Rel_Back, and RelIndex MUST use the ordinary layered ports without a fixed side. [just parity]
- c4-50: Under the cell profile, every point of a re-routed directional relation MUST name a drawable cell of the canvas: when a stub or run reaches the coordinate `W` or `H` of the canvas, the canvas MUST grow to `W + 1` or `H + 1`, so that no route point lies outside the canvas and no cell write is clipped. The vector profile MUST keep its canvas. Go, Rust, and the Lean reference MUST apply the same growth. [just parity]
- c4-43: Missing relation endpoints, duplicate aliases, unknown style targets, arbitrary named optional fields, and invalid row hints MUST NOT gain semantic errors absent from the database checks. [just oracle]
- c4-44: Every C4 schema key MUST have a config registry row; C4-specific font, colour, dimension, spacing, wrapping, and row settings MUST be accepted-ignored because the approved layered and token rules do not read them. [just gen-check]
